Инструменты склада

Работают прямо в браузере: файлы обрабатываются на вашем устройстве и никуда не отправляются.

Сборка поставки Сканируем коробки, вводим количество - получаем заполненный файл для Ozon. Работает с телефона. Открыть → Пересчёт упаковок Из файла поставки считает штуки: количество × фасовка из артикула, одинаковые артикулы складывает. Открыть →

На телефоне: сначала сохраните нужные файлы Excel в приложение «Файлы» (в Telegram - «Поделиться» → «Сохранить в Файлы»), потом откройте инструмент и выберите их. Страницу удобно добавить на домашний экран: «Поделиться» → «На экран Домой».
