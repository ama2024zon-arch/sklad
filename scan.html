Сборка поставки

Заполняет лист «Состав ГМ поставки»: сканируем коробки, инструмент подставляет артикул и собирает файл для Ozon.

Файл №1 Выгрузка товаров products_export - штрихкоды и артикулы
Файл №2 Шаблон поставки файл Ozon с листом «Состав ГМ поставки» (и «Список транспортного ГМ», если поставка на паллетах)
Товаров0
Коробок0
Паллет0

Загружен только шаблон поставки. Этого хватит, чтобы собрать готовый файл из результата сканирования. Для ссылки на телефон, сканирования и переписи нужен ещё файл №1 - в нём штрихкоды товаров.

Ссылку для телефона можно сделать только от адреса в интернете - с адреса файла на компьютере телефон ничего не откроет. Введите адрес один раз, он запомнится.

Как этим пользоваться
  1. На компьютере загрузите файл №1 (выгрузка товаров) и файл №2 (шаблон поставки от Ozon).
  2. Нажмите «Собрать для телефона» - скачается один файл. Отправьте его себе в мессенджер и откройте на телефоне: данные уже внутри, интернет не нужен.
  3. На телефоне поставьте номер паллеты - он держится, пока не смените. Сканируйте коробки одну за другой и вводите количество.
  4. Когда паллета собрана, поменяйте номер паллеты и продолжайте - нумерация коробок идёт сквозная.
  5. «Сохранить файл для Ozon» - получится тот же файл №2, но с заполненными столбцами: ШК товара, артикул, количество и ШК паллеты.

Если коробки уже переписаны вручную в Лист1 в формате номер=артикул=количество, файл заполняется кнопкой «Заполнить из Лист1» - сканировать ничего не нужно.
