Пересчёт упаковок

Файл поставки превращается в сводку: количество умножается на фасовку из артикула, одинаковые артикулы складываются в одну строку.

Перетащите файл сюда или нажмите, чтобы выбрать
Excel (.xlsx) или .csv. Столбец A - артикул, столбец C - количество. Файл остаётся на вашем компьютере, никуда не отправляется.

    Ничего не найдено

    В выгрузке два столбца - артикул и количество. Колонка «Строк» показана только на экране: сколько позиций файла сложилось в этот артикул.

    Как считается
    1. Артикул из столбца A делится по последнему дефису: 630607-100 → артикул 630607, фасовка 100.
    2. Количество из столбца C умножается на фасовку: 5 × 100 = 500 штук.
    3. Одинаковые артикулы складываются: две строки 210523-1 по 16 и 12 дают 210523 → 28.

    Если после дефиса стоит не число или дефиса нет, фасовка считается равной 1, а строка попадает в список «Проверьте вручную» - она всё равно учтена в сводке.
